# Algorithm

Start
Read Num
Set Counter = 2
Check if Num > 1
If No, Print "Not Prime" and go to End.
If Yes, continue.
Check if Counter == Num
If Yes, Print "Prime" and go to End.
If No, continue.
Check if Num % Counter == 0
If Yes, Print "Not Prime" and go to End.
If No, set Counter = Counter + 1 and go back to Step 5.
End

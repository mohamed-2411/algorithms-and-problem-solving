# Algorithm

1. **Start**
2. **Read** `Day`
3. Check if `Day >= 1` **and** `Day <= 7`

   * If **No**, print `"Wrong Day"` and go back to **Step 2**.
   * If **Yes**, continue.
4. Check if `Day == 1`

   * If **Yes**, print `"It's Sunday"` and go to **End**.
5. Check if `Day == 2`

   * If **Yes**, print `"It's Monday"` and go to **End**.
6. Check if `Day == 3`

   * If **Yes**, print `"It's Tuesday"` and go to **End**.
7. Check if `Day == 4`

   * If **Yes**, print `"It's Wednesday"` and go to **End**.
8. Check if `Day == 5`

   * If **Yes**, print `"It's Thursday"` and go to **End**.
9. Check if `Day == 6`

   * If **Yes**, print `"It's Friday"` and go to **End**.
10. If none of the above, print `"It's Saturday"`.
11. **End**

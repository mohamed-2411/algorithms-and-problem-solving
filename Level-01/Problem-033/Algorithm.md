# Algorithm

1. Start.
2. Read Grade.
3. While (Grade > 100 OR Grade < 0)
      Read Grade.
4. If Grade >= 90
      Print "A"
   Else If Grade >= 80
      Print "B"
   Else If Grade >= 70
      Print "C"
   Else If Grade >= 60
      Print "D"
   Else If Grade >= 50
      Print "E"
   Else
      Print "F"
5. End.

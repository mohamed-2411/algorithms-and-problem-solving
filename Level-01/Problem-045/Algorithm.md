# Algorithm

1. **Start**
2. **Read** `Month`
3. Check if `Month >= 1` **and** `Month <= 12`

   * If **No**, print `"Wrong Month"` and go back to **Step 2**.
   * If **Yes**, continue.
4. Check if `Month == 1`

   * If **Yes**, print `"January"` and go to **End**.
5. Check if `Month == 2`

   * If **Yes**, print `"February"` and go to **End**.
6. Check if `Month == 3`

   * If **Yes**, print `"March"` and go to **End**.
7. Check if `Month == 4`

   * If **Yes**, print `"April"` and go to **End**.
8. Check if `Month == 5`

   * If **Yes**, print `"May"` and go to **End**.
9. Check if `Month == 6`

   * If **Yes**, print `"June"` and go to **End**.
10. Check if `Month == 7`

    * If **Yes**, print `"July"` and go to **End**.
11. Check if `Month == 8`

    * If **Yes**, print `"August"` and go to **End**.
12. Check if `Month == 9`

    * If **Yes**, print `"September"` and go to **End**.
13. Check if `Month == 10`

    * If **Yes**, print `"October"` and go to **End**.
14. Check if `Month == 11`

    * If **Yes**, print `"November"` and go to **End**.
15. Otherwise, print `"December"`.
16. **End**

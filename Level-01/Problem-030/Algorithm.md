# Algorithm

1. Start.
2. Read N.
3. If N <= 0:
      Print "Factorial must be a positive number."
      Go back to Step 2.
4. Set Counter = N + 1.
5. Set Factorial = 1.
6. Repeat:
      a. Counter = Counter - 1.
      b. Factorial = Factorial * Counter.
   Until Counter = 1.
7. Print Factorial.
8. End.
